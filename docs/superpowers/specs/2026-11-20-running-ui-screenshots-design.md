# 真实运行界面截图设计

## 目的

让用户看到当前代码在真实浏览器、真实 HTTP 服务和测试数据库中渲染的页面，纠正将 Askama 模板源码误当成网站预览的交付错误。

## 范围与约束

- 沿用现有 Linux Playwright E2E 环境和虚构测试数据，不部署公开网站，不接触真实用户信息。
- 截取公开的 `/opportunities` 桌面界面；在现有测试账号可用时，截取 `/tenders` 列表与一份虚构 PDF 的分析报告。
- 截图必须来自浏览器访问运行中的服务，且等待主要内容和样式加载；不能使用静态 HTML、模板文件或设计稿替代。
- 仅在 Chromium 测试中产出截图，由 GitHub Actions artifact 保存，再下载给用户查看。
- 截图是当前开发版本的视觉证据，不代表已部署、已上线或使用真实项目数据。

## 方案选择

选择在已有 E2E 流程中截屏：测试环境已具备服务器、数据库、浏览器和合成数据，改动最小且可复现。本机直接启动受数据库和构建环境限制；公开测试站点需要额外的部署平台、密钥与维护决策，本轮不做。

## 验收

- 机会页、招标列表和报告截图均能在自动测试产物中找到，图片不是空白或模板源码。
- 对应浏览器用例和 CI 通过；若某页无法安全生成，如实说明并交付已验证的截图。
- PR 保持草稿，不合并，不把截图称为线上网站。
